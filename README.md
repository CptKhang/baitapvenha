# E-commerce UI Improvement - Phong Vũ

## 1. Giới thiệu
Dự án cá nhân bài tập Chương 1 môn Phát triển ứng dụng WEB/TMĐT. Đề tài thực hiện cải tiến giao diện khu vực thanh toán, nổi bật phương thức thanh toán bằng Ví điện tử MoMo.

## 2. Website tham khảo
- Tên website: Phong Vũ
- URL: https://phongvu.vn/
- Khu vực đã khảo sát: Trang chủ, Danh mục, Chi tiết sản phẩm, Tìm kiếm, Giỏ hàng & Thanh toán.

## 3. Chức năng cải tiến
- Hiển thị tóm tắt giỏ hàng.
- Lựa chọn phương thức thanh toán với thiết kế nổi bật cho Ví MoMo.
- Hiển thị mã QR mẫu và hướng dẫn thao tác quét mã MoMo trực quan.
- Giao diện Responsive tương thích với máy tính và điện thoại.

## 4. Công nghệ sử dụng
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)

## 5. Cách chạy
- Mở trực tiếp file `index.html` bằng trình duyệt web (Chrome, Edge, Firefox).
